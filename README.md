# Roamly — "Know it. Walk it. Love it." 🌍

An interactive, smart city exploration and decision engine web app that turns scattered city data into verified, actionable insights.

---

## 🚀 How to Run Locally

### Option 1: One-Click Launcher (Recommended)
1. Double-click **`start_website.bat`**.
2. It will spin up a local server and automatically open **`http://localhost:3000`** in your browser.
3. *Why a local server?* Browsers grant full microphone, speech synthesis, and geolocation permissions on `localhost`.

### Option 2: Direct File Open
- Simply double-click **`index.html`** to open it in Chrome, Edge, Brave, or Firefox.

---

## 🌐 How to Host / Publish Online for Free

Because **Roamly** is a 100% self-contained single-page web app with zero dependencies or build steps, you can publish it live to the web in under 60 seconds using any of these free hosting services:

### 1. Netlify Drop (Easiest - 10 seconds, No account needed)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `roamly` folder onto the webpage.
3. You will instantly get a live public URL (e.g. `https://roamly-city.netlify.app`).

### 2. GitHub Pages (Free forever)
1. Create a new GitHub repository named `roamly`.
2. Upload `index.html`.
3. In repository **Settings** &rarr; **Pages**, set branch to `main` (root) and click **Save**.
4. Your website is live at `https://<your-username>.github.io/roamly/`.

### 3. Vercel
1. Go to [vercel.com](https://vercel.com).
2. Click **Add New Project** &rarr; Import your GitHub repo or drag the folder.
3. Click **Deploy**.

## 🌟 Signature Features
- **Vibe Compass**: Radial wheel (Chill, Foodie, Heritage, Thrill, Budget, Night Owl) that re-ranks map & advice in real-time.
- **City Mood Ring**: Live weather, traffic, and community sentiment headline.
- **Navi AI Assistant**: Converts natural-language queries (e.g. *"rainy night, under $20, with family"*) into ONE comprehensive plan with backup contingencies and Text-to-Speech.
- **SafePath Route Comparison**: Fastest vs. Safest walking route side-by-side with risk scores, emergency hub coordinates, and a "Walk With Me" active safeguard bar.
- **Pulse Insights & Citizen Reports**: In-browser multilingual NLP scoring topics, sentiment, audio waveform recording, duplicate detection, and audit timelines.
- **Time Slider (City Time Machine)**: Re-evaluates safety, crowds, lighting, and heritage ("Then vs Now") from 6 AM to 2 AM.
- **Collectible Passport Stamps**: Unlocks SVG stamps for completed walks, report contributions, and adventures.
